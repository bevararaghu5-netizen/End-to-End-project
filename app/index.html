About This Project

This project demonstrates an end-to-end DevOps workflow. Application source code is maintained in GitHub and the Jenkins pipeline automates the build process. Docker is used to package the application into a container image, while Kubernetes manages the application deployment and replicas. Prometheus collects Kubernetes metrics and Grafana provides monitoring dashboards for the deployed application and infrastructure.
